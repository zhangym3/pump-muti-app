# 泵阀控制 APP 1.2.1 交互说明

2026-10-21，Jetpack Compose 实现。四个底部入口始终可见：控制、设备、记录、设置。标签页之间平级切换，不叠加页面历史。

## 常用操作

| 目的 | 路径与行为 |
| --- | --- |
| 定量出水 | 控制页直接设水量、选速度、点选阀门 → 检查并启动 → 一次确认参数。接受后原位显示任务；结束后同页可编辑下一次任务。 |
| 查看本次结果 | 控制页顶部显示最近任务摘要，点击“展开结果”；结果尚未核实或任务执行中自动展开。 |
| 查看历史脉冲 | 记录页点击任务卡片，直接在列表内展开水量、总脉冲与异常原因；再次点击收起。 |
| 复用历史参数 | 记录详情 → 填入控制页草稿。只选当前可用阀门，仍须核对并确认启动。 |
| 独立试泵 | 设备页 → 展开测试，同页选择速度、时长、启动或停止；无需进入设备维护。 |
| 从机组网 | 设备页 → 添加设备，在当前页面显示候选及组网结果。收起搜索结果只隐藏内容，不取消主机正在执行的组网。 |
| 三档流量调校 | 设置页直接选择节点、读取、编辑或按量杯结果计算系数；切到控制或记录后回来，当前输入保留。 |
| 连接主机 | 所有标签页右上角固定“连接/主机”入口，打开底部弹层；关闭回到原标签页和原草稿。 |

移除独立的阀门选择页、任务预览页、出水结果页和水泵二级页。控制页提供全选在线、反选、清空；统一和单独设置都在当前页面操作。移除重复的水量滑条和执行顺序卡片，减少纵向滚动。

## 切换与返回

- 每个标签页分别保留滚动位置和可保存的展开/编辑状态；Activity 重建后恢复草稿、当前标签页、记录展开、水泵面板与时限。
- 系统返回先收起当前可见的记录详情或水泵面板，再回控制页；控制页使用 Android 默认返回行为。其他标签页的展开状态不会拦截本页返回。
- 连接弹层、启动确认和维护确认先处理自身关闭，返回不提交操作。
- 启动确认不跨 Activity 重建恢复，重新启动前需再次核对。
- 接受任务时控制页滚到任务顶部；任务结束后不强制跳页，也不弹出新建任务页面。下一次任务仍需手动启动并确认。
- 记录仅在用户点击“填入控制页草稿”时切换控制页；水泵启动锁入口直接切到设备并展开测试区域。

## 启动、停止与结果

“检查并启动”同时校验草稿参数与主机当前状态，暂不可启动原因直接显示在控制页，不需进入预览页查找。确认框列出逐路目标、总目标、单路时限和主机已确认速度；确认期间清单、状态、档位或原任务结果发生变化，会重新校验并禁用启动。

执行中和待确认任务仅在底部固定栏保留一个跨标签页的停止入口，任务卡内不重复显示；其他标签页提供“查看当前任务”。停止仍需主机确认。返回、切换标签和关闭弹层只影响显示，不停止或重新发送任务。

逐阀结果中，FAULT 显示“异常停止”，人工停止显示“已停止”，只有 DONE / TARGET 且计量有效才显示“已完成”。累计量和脉冲数有效不代表任务已成功达量。

GATT 写入成功不代表设备接受。原请求身份、序号、防重放、超时、结果对账、断连恢复和持久化规则保持原行为；不自动重发启动。历史任务只能复制到新草稿，无法从记录详情直接启动。

## 设备与调校

真实设备按主机稳定槽位排序，后台清单轮询不重排阀门卡片。清单过期、离线或未启用的阀门不可选，不生成占位节点。水量范围 50–2000 mL、步进 50 mL；单路时限 1–240 秒，在设置页编辑。

水泵测试同页展开后仍由 MCU 计时，默认 5 秒，可选 3/5/10 秒。速度为低 50%、中 75%、高 100%；选速本身不启泵，测试中切档不延长原截止时间。启动锁解除保留明确确认。设备维护仅收纳重置组网等低频操作。

每节点三档霍尔校准、主机 NVS 保存和任务 K 下发行为见 [FLOW_CALIBRATION.md](FLOW_CALIBRATION.md)。校准表单的未保存编辑在切标签后保留；切换节点或主机返回新版本参数时使用对应的新快照。
