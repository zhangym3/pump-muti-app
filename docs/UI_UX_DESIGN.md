# 泵阀控制 APP 1.2.0 UI / UX

2026-10-16，Jetpack Compose 实现，固定 Master PIN 直连。

## 控制

顶部连接状态与 Master 摘要展示真实配对从机数、在线数及同步状态。没有完整清单显示“从机数量待同步”；只有完整空清单才显示0台。阀门编号来自 Master 稳定槽位，不生成32个占位设备；离线、未配置及过期清单不可选。选中节点逐路执行相同每路水量，启动前保留定量任务确认。历史草稿只保留当前可选节点，原任务存档掩码不变。

## 设备

真实清单展示槽位、别名、地址、在线状态和现场配置状态。未完成握手登记的已配对从机显示待配置；提供重试连接配置。别名只保存在本手机。

“让 Master 扫描附近从机”通过加密业务通道请求 Master 执行 PB-ADV 发现；约15秒后显示本工程待配网从机，用户明确选择连接组网。依次展示配对、密钥绑定/订阅、等待握手及完成；收到合法 HELLO 后更新清单。组网期间禁止新出水、新试泵和调速，停止原任务/测试保留。旧 Node 网络由新版 Master 固件启动时自动清理并重启；APP 只提示等待主机重连，不提供现场迁移按钮或迁移确认。

水泵页面只保留通水测试，按钮为启动测试 / 停止测试。低档50%、中档75%、高档100%，默认5秒，可选3/5/10秒。不显示方式切换、空转文案、准备或短时运行确认勾选。选档等待 Master 确认，选档本身不启动输出；测试中切档不延长原截止时间。已知测试停止不依赖快照新鲜度和本地存储健康。主机执行定时，手机不模拟实际运行传感器反馈。

## 记录与设置

本地记录按任务身份和序号保存，水量缺失显示未知而非0。历史只可填入新草稿，不能直接重发。设置保留单路时限、维护说明和二级连接诊断；现场系数、输出启用及定量 BOOT_LOCK 复位仍通过 USB 完成。

## 状态一致性

首次连接由 Android 系统输入 PIN，等待绑定、加密订阅和 MTU 成功后开放命令。GATT 写入成功不代表 Master 接受。清单只有 BEGIN/NODE/END 完整且匹配当前 epoch/request、计数、唯一地址/槽位时才整体更新；8秒接收超时、15秒过期均禁止新任务，不能把缺包当作0台。

BLE 断连或 Master epoch 变化清除旧网络清单、候选和状态；已有任务、试泵及停止记录保留待查询，绝不自动启动。配对表在 Master NVS 持久化，重连重新读取真实清单。
