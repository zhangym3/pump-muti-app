# 三档霍尔流量校准

设置 → 霍尔流量分档调校。每个从节点分别保存低档 50%、中档 75%、高档 100% 的计量系数；存储位置是主机 NVS，更换手机或重启主机后可重新读取。

## 操作

1. 同步更新 APP、主机和从机固件，连接主机，等待从节点清单同步。
2. 在设置页选择从节点，自动读取主机保存的三档系数。尚未调校时三档均使用该节点原有基础系数。
3. 在控制页只选择这一节点和待测档位，完成一次定量出水。记录页查看该次结束后的总脉冲数，用量杯测量实际出水量。
4. 返回设置页，选择相同节点与档位，填写总脉冲数和量杯实测 mL，点击“填入…系数”。不要填写 APP 根据脉冲计算出的水量。
5. 三档可分别测量，也可直接编辑。点击“保存三档调校”并确认，等待“主机已保存三档系数，下次定量任务生效”。每档重新测量验证，重复取稳定值。

计算公式：`每毫升脉冲数 = 总脉冲数 / 量杯实测 mL`。

例如 2940 脉冲、实测 490 mL，系数为 **6.000 脉冲/mL**。之后该档位出水 500 mL 的目标是 3000 脉冲。系数越大，相同目标水量需要的脉冲越多。保存三个档位时未修改档位沿用读回值。

支持 0.001–1000.000 脉冲/mL，最多三位小数。计算按最接近的 0.001 脉冲/mL 取值；脉冲数、实测水量必须大于零。没有脉冲时需先恢复流量计信号，修改系数不能恢复脉冲输入。校准只影响定量计量，不改变 PWM 占空比或独立定时试泵。

## 生效和异常处理

- 主机成功写入并读回 NVS 后才确认保存；下次定量任务按已确认的泵速选择对应系数，正在执行的任务不改变系数。
- 有定量任务、独立试泵、组网、未知结果或存储故障时禁止保存。所有三档一次提交，避免只保存一部分。
- 超时、断连或存储错误不会自动重发保存。重新连接并读取主机保存值后核实结果。
- 多手机修改或节点基础系数、版本变化会触发 `STALE`；核对最新读回值后重新保存。旧参数不会应用到身份不匹配的节点。
- 已调校任务要求从机支持校准功能。旧从机在任务预检阶段被拒绝，主机不发送该任务的 PREPARE/START。
- 首次更新后需要实际量杯验收；软件模拟测试不代表出水精度已经达标。

## APP 与主机协议

一条命令不超过 159 字节，回复不超过 191 字节。地址使用十六进制，其他数字均为十进制。`K` 使用整数，单位为 **脉冲/1000 mL**，即 UI 的脉冲/mL 乘以 1000；`5880` 表示 `5.880 脉冲/mL`。

```text
cal-get EPOCH REQUEST SLOT ADDRESS
cal-set EPOCH REQUEST SLOT ADDRESS REVISION BASE_K BASE_VERSION LOW MID HIGH
```

`SLOT=1..32`；`REQUEST` 是本次读取/保存的非零请求号；`REVISION` 是最近读回的调校版本（初始为 0）；`BASE_K` 和 `BASE_VERSION` 必须与读回的节点基础配置一致。成功保存使调校版本加 1。重复或旧版本保存返回 `STALE`，不会重复写入。

```text
cal-get 7 42 1 0002
CAL epoch=7 req=42 slot=1 addr=0002 rev=0 bk=5880 bv=1 low=5880 mid=5880 high=5880 reply=OK
cal-set 7 43 1 0002 0 5880 1 6000 6200 6500
CAL epoch=7 req=43 slot=1 addr=0002 rev=1 bk=5880 bv=1 low=6000 mid=6200 high=6500 reply=OK
```

`HELLO calibration=1` 宣告主机支持这些命令。APP 仅接受匹配当前启动 epoch、请求号、槽位与地址的回复；保存确认还需三个值一致、版本恰好加 1、基础配置一致。

Mesh V4 的 PREPARE 仍为 39 字节，原 flags 字段 bit 0 (`0x01`) 表示本次任务使用主机提供的校准 K。新增能力位 `0x0200`；其他 flags 位不允许。保留未调校任务的基础 K 校验、版本校验、目标脉冲校验、租约与异常停止机制。定量任务结果仍保留本次实际使用的 K，修改配置不会重算历史结果。不增加运行期间实时流量上报或额外校准 Mesh 往返。
